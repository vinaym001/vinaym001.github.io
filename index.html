RAG Compliance Assistant

A conversational assistant that answers natural-language questions over structured compliance records. For each question, the model calls predefined tools that query the database, then answers from the records they return. Results are limited to the clients each user can access, and credentials and other sensitive fields are removed before data reaches the model. Built on the Anthropic Claude API.

  • Conversation history

    Stored by the application and sent with each request, so follow-up questions keep their context.

  • Access control

    Every query is limited to the clients the signed-in user can access.

  • Tool-based retrieval

    The model calls predefined tools backed by existing service logic, so results match the dashboards.

  • Field allow-list

    Only approved fields are returned to the model. Credentials are never included.

    client gstin due_date portal_username password

  • Streaming responses

    Answers stream as they are generated, as text, tables and stats.
